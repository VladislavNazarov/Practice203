# Стратегия контейнеризации

## 1. Выбор базового образа

| Этап | Образ | Размер | Обоснование |
|------|-------|--------|-------------|
| Build | python:3.12-slim | ~150 MB | Содержит pip и заголовки для сборки зависимостей |
| Runtime | python:3.12-slim | ~150 MB | Минимальный образ с Python без инструментов сборки |

Выбран `python:3.12-slim` вместо `alpine`:
- Совместимость с бинарными пакетами (psycopg2, uvloop)
- Отсутствие проблем с musl vs glibc
- Баланс размера и совместимости

## 2. Управление переменными окружения

| Переменная | Назначение | Значение по умолчанию |
|-----------|-----------|----------------------|
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql://weather:weather@db:5432/weather_db` |
| `REDIS_URL` | Строка подключения к Redis | `redis://cache:6379/0` |
| `APP_PORT` | Порт приложения | `8000` |
| `APP_HOST` | Хост приложения | `0.0.0.0` |
| `LOG_LEVEL` | Уровень логирования | `info` |
| `CACHE_TTL` | Время жизни кэша в секундах | `900` |
| `EXTERNAL_API_KEY` | Ключ внешнего API погоды | - |
| `WORKERS` | Количество воркеров uvicorn | `2` |

Секреты (`EXTERNAL_API_KEY`, пароли БД) не хранятся в коде и передаются через Docker secrets или переменные окружения CI.

## 3. Оптимизация

### Multi-stage build

Двухэтапная сборка:
1. **Build stage** - установка зависимостей с pip в `/install`
2. **Runtime stage** - копирование только установленных пакетов и кода приложения

### Оптимизация слоев

Порядок инструкций в Dockerfile оптимизирован для кэша Docker:
1. Копирование `requirements.txt` (меняется редко)
2. Установка зависимостей (кэшируется между сборками)
3. Копирование исходного кода (меняется часто)

### Сравнение размера образа

| Подход | Размер образа |
|--------|--------------|
| python:3.12 (без оптимизации) | ~1.05 GB |
| python:3.12-slim + multi-stage | ~220 MB |
| **Сокращение** | **~79%** |

## 4. Безопасность

- Приложение запускается от непривилегированного пользователя `appuser`
- Используется `--no-cache-dir` для pip (не хранить кэш в образе)
- Минимальный набор файлов в runtime-слое (нет исходников сборки)
