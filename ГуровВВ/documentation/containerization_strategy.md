# Стратегия контейнеризации Git4CodeSys

## Выбор базового образа
- **python:3.11-slim**:  
  Сбалансированный образ (~150 MB), содержит минимальный набор системных библиотек.  
  Значительно легче стандартного `python:3.11` (~900 MB).  
- Отказ от `alpine`: библиотека `lxml` может испытывать проблемы совместимости с musl libc. Slim основан на Debian — совместимость без лишних зависимостей.

## Управление ENV
Переменные окружения, задаваемые в `docker-compose.yml`:

| Переменная     | Назначение                      |
|----------------|---------------------------------|
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `REDIS_URL`    | Адрес Redis для кэширования     |
| `SECRET_KEY`   | Ключ для подписи (JWT и т.п.)   |
| `LOG_LEVEL`    | Уровень логирования             |

В коде читаются через `os.getenv`.

## Оптимизация образа (Multi-stage)
- **Stage 1 (build):** установка зависимостей, компиляция `lxml`.
- **Stage 2 (runtime):** только собранные пакеты и код.

| Версия           | Размер       |
|------------------|--------------|
| Одноэтапный slim | ~200 MB      |
| Multi-stage slim | ~130 MB      |
| Стандартный      | ~350 MB      |

Сокращение ~35% за счёт Multi-stage сборки.
